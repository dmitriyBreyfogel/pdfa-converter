# PDF/A Converter

Веб-приложение для создания архивных копий документов в формате PDF/A. Загрузите файл, выберите профиль PDF/A-1b, PDF/A-2b или PDF/A-3b и скачайте результат после проверки.

**Входные форматы:** PDF, DOC, DOCX, XLS, XLSX, PPTX. Максимальный размер файла — 50 МБ.

## Как работает

1. Браузер отправляет файл и выбранный профиль на `POST /api/convert`.
2. Бэкенд проверяет загрузку и конвертирует офисные документы через LibreOffice, а исходные PDF — через Ghostscript.
3. Готовый файл проверяется на соответствие выбранному профилю с помощью veraPDF. Только после успешной проверки он возвращается для скачивания.

Если результат не соответствует PDF/A, интерфейс предлагает скачать XML-отчёт veraPDF. При ошибке обработки пользователь видит сообщение «Ошибка конвертации».

## Запуск

Нужен Docker с Docker Compose. Из корня проекта выполните:

```bash
docker compose up -d --build
```

Откройте <http://localhost:3000>. Команда запускает фронтенд и бэкенд вместе; первый запуск может занять несколько минут из-за сборки образов и загрузки зависимостей.

Остановить приложение:

```bash
docker compose down
```

## API

`POST /api/convert` принимает `multipart/form-data`:

| Поле     | Значение                              |
| -------- | ------------------------------------- |
| `file`   | Входной файл до 50 МБ                 |
| `target` | `PDF_A_1b`, `PDF_A_2b` или `PDF_A_3b` |

При успехе API возвращает PDF с `Content-Disposition: attachment`. Ошибки приложения возвращаются в JSON с полями `code`, `message` и `details`; при несоответствии PDF/A XML-отчёт находится в `details.report`.

## Что учитывать

- Конвертация может изменить шрифты, интервалы, цвета, расположение элементов и отдельные свойства PDF.
- При преобразовании исходного PDF в PDF/A-1b страницы с прозрачностью могут стать изображениями. Текст на них может перестать выделяться и копироваться.
- veraPDF проверяет соответствие стандарту PDF/A, но не сравнивает результат с исходным документом. Если важен точный внешний вид, просмотрите скачанный файл.

## Структура проекта

- `backend/` — Java 21, Spring Boot, конвертация и проверка PDF/A.
- `frontend/` — React, TypeScript, Vite; в Docker статические файлы и API обслуживает Nginx.
- `compose.yaml` — совместный запуск сервисов.
